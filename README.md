# 🌟 AutoPilot eCom

> Site React pour automatisation IA d'une boutique e-commerce

## 📦 Technologies utilisées

- React 18
- Firebase Hosting (optionnel)
- Tailwind CSS (non activé par défaut)

## 🗂 Structure du projet

```
src/
├── App.js
├── index.js
├── data/project.js
├── components/HeroSection.js
└── pages/Home.js
```

## 🚀 Installation locale

```bash
git clone https://github.com/votre-utilisateur/autopilot-ecom.git
cd autopilot-ecom
npm install
npm start
```

## ☁️ Déploiement Firebase Hosting

```bash
npm run build
firebase login
firebase init
firebase deploy
```

## ✏️ Personnalisation

- Modifier le contenu dans `src/data/project.js`
- Adapter les styles ou composants selon vos besoins
